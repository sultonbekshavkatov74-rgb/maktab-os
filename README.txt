Maktab OS — LOGIN + 3 TA ROLLI PANEL

Papkalar:
- login/      Kirish sahifasi, rol tanlash va demo akkaunt tekshiruvi
- school/     O‘quv markazining asosiy sayti
- dashboard/  Direktor, o‘qituvchi va o‘quvchi uchun rolga qarab o‘zgaradigan panel

Ishga tushirish:
1. ZIP arxivni oching.
2. VS Code'da shu papkani oching.
3. school/index.html faylini Live Server bilan oching.
4. Login sahifasiga o'tish uchun saytdagi "Kirish"ni bosing. Yoki login/index.html faylini oching.
5. Login ma’lumotlari:

   Direktor:   login direktor   | parol 1234
   O‘qituvchi: login oqituvchi  | parol 1234
   O‘quvchi:   login oquvchi    | parol 1234

6. Akkaunt turini mos tanlang. Muvaffaqiyatli kirgach dashboard ochiladi.
7. Chiqish tugmasi login sahifasiga qaytaradi.

MUHIM:
Bu front-end demo. Login tekshiruvi JavaScript ichidagi demo akkauntlar bilan ishlaydi va haqiqiy xavfsizlik bermaydi.
Haqiqiy foydalanuvchi akkauntlari, ma’lumotlar bazasi, parol xavfsizligi va rollar uchun backend (masalan Node.js + database) kerak.
Rasmlar internetdan yuklanishi mumkin.
